# MouseForge Web

Frontend React do MouseForge PDV.

## Stack

- React 18
- Vite
- TypeScript
- Tailwind CSS
- TanStack Query
- React Hook Form
- Sonner
- Lucide React

## Configuração

```bash
npm install
cp .env.example .env
npm run dev
```

Variável esperada:

```bash
VITE_API_URL=http://localhost:3333
```

## Scripts

```bash
npm run dev
npm run build
npm run preview
npm run lint
```
